# Outside the IDE

One folder per polaroid. Drop photos or videos in and they show up on the site;
clicking a polaroid flips to the next file.

- `travel/`, `hackathon-wins/`, `design-and-edits/`
- Order = file name order, so prefix with `01-`, `02-`, …
- Images: jpg, png, webp, gif. Videos: mp4 (H.264) or webm; they play muted and loop.
  iPhone `.mov` works in most browsers; `.heic` photos don't, so export them as jpg.
- Any shape is fine: the frame follows the photo (9:16, 16:9, …).
- An empty folder shows a "photo coming soon" placeholder.
